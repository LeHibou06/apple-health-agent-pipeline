# Privacy and security

Health information is sensitive personal data. Keep the service off the public internet, use a private network or authenticated TLS reverse proxy, use separate random tokens, restrict filesystem permissions, encrypt backups, and never commit real payloads, databases, or secrets.

Give the AI layer only bounded read-only tools. Consider deleting raw JSON after successful processing and a short troubleshooting window. This project is not intended for diagnosis, treatment decisions, emergency detection, or clinical monitoring.
